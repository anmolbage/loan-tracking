# Loan Tracking

Phone app (PWA) for the Regional Manager, RO Hazaribag, to track loan proposals across 40 branches:
stage, who holds the file, days with them, and the next follow-up. Data lives in a Google Sheet
through an Apps Script web app (`apps-script/Code.gs`); sign-in is username + PIN.

Setup steps are in the project folder's README (kept outside this repo with the staff contact list).
